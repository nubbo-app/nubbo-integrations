One workspace for all your S3 storage. Automate it from Make.

Nubbo works with AWS S3, Cloudflare R2, DigitalOcean Spaces, Wasabi, Backblaze B2 and any S3-compatible endpoint.

With this app your scenarios can:

- react to new files, new file request uploads and any activity in your space;
- list, search, upload, download, move, rename, label, trash and restore files and folders;
- create and manage share links, file requests, galleries, embeds, automation rules, labels and projects.

Files travel straight between Make and your storage provider through temporary links. Nubbo never stores the content of your files.

To connect, create an API key in Nubbo under **Settings › API** (Pro plan) or **Team › API** (team owners and admins). Encrypted (zero-knowledge) items are never readable through the API.

API reference: https://api.nubbo.app/v1/docs
