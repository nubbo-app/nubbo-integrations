# Nubbo integrations

Official integrations for [Nubbo](https://nubbo.app), the multi-cloud manager for S3-compatible storage.

| Folder | Integration | Package |
| --- | --- | --- |
| [`n8n`](n8n) | n8n community nodes: the Nubbo node and the Nubbo Trigger | `n8n-nodes-nubbo` on npm |

Every integration talks to the [Nubbo API](https://api.nubbo.app/v1/docs) with an API key from **Settings › API** or **Team › API** in Nubbo.
